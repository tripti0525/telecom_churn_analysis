# Telecom Churn Analysis Dashboard

## 📊 Project Overview

The **Telecom Churn Analysis Dashboard** is an interactive Power BI
project designed to analyze customer churn patterns, customer
demographics, network behavior, device usage, buffering experience,
content preferences, and subscription-plan performance.

The dashboard transforms customer data into clear KPIs and interactive
visualizations to help identify churn trends and support data-driven
customer retention decisions.

------------------------------------------------------------------------

## 🎯 Project Objectives

-   Measure the overall customer churn rate.
-   Compare active and churned users across different demographic
    segments.
-   Analyze churn behavior by age group and gender.
-   Identify churn patterns across device and network types.
-   Understand the relationship between buffering time and customer
    churn.
-   Analyze user count and churn rate across top content genres.
-   Compare churn movement across subscription plans.
-   Provide interactive filtering for payment method and auto-renewal
    behavior.

## 📈 Dashboard Analysis

### 1. Demographic Analysis

The dashboard compares **Churned vs. Active Users** across:

-   Gender
-   Age Groups: 18--25, 26--35, 36--45, and 46+

This helps identify customer segments with comparatively higher churn
and understand the distribution of active and churned customers.

### 2. Device Type Analysis

Churn rate is compared across:

-   Android
-   Web
-   iOS

The displayed churn rates are approximately **30.32%--30.95%**, showing
relatively similar churn levels across device types.

### 3. Buffering Time Analysis

The dashboard evaluates churn rate across buffering-time ranges:

-   0--1 sec
-   1--2 sec
-   2--3 sec
-   3--4 sec
-   4+ sec

The displayed churn rate ranges from **29.01% to 31.71%**, helping
evaluate whether streaming/buffering experience is associated with
customer churn.

### 4. Genre Analysis

User count and churn rate are analyzed for the following top genres:

-   Rock
-   Pop
-   Hip-Hop
-   Classical
-   Jazz
-   EDM

This provides insight into customer preferences and their relationship
with churn behavior.

### 5. Network Type Analysis

Churn rate is compared across:

-   5G
-   WiFi
-   4G

The dashboard shows churn rates of approximately **31.87%, 30.30%, and
29.93%**, respectively.

### 6. Subscription Plan Analysis

The dashboard compares **Previous Plan vs. Current Plan** churn rates
and calculates churn difference and percentage change.

  --------------------------------------------------------------------------
  Subscription   Previous Churn  Current Churn          Churn Churn % Change
  Plan                     Rate           Rate     Difference 
  -------------- -------------- -------------- -------------- --------------
  Free                   27.40%         28.88%         +1.48%         +5.41%

  Family                 32.04%         32.76%         +0.71%         +2.22%

  Premium                32.67%         30.61%         -2.07%         -6.33%
  --------------------------------------------------------------------------

**Key observation:** 
The Premium plan shows a **6.33% decrease in
churn**, while Free and Family plans show increases.

## 💡 Key Insights

1.  The dashboard records an overall **30.70% churn rate**.
2.  Approximately **1K users are churned**, compared with around **3K
    active users**.
3.  Churn rates across device types are relatively close, ranging from
    about **30.32% to 30.95%**.
4.  Buffering-time segments show churn rates between **29.01% and
    31.71%**.
5.  Network-type analysis shows the highest displayed churn rate for
    **5G (31.87%)** and the lowest for **4G (29.93%)**.
6.  The **Premium subscription plan** improved from **32.67% to
    30.61%**, representing a **6.33% decrease in churn**.
7.  Free and Family plans show an increase in churn compared with their
    previous-plan churn rates.
